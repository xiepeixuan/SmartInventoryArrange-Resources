## 使用

将任意 `test_*.txt` 拖到上一级目录的 `SmartLayoutRenderer.exe`，即可重新生成同名 `.layout.png` 和 `.layout.json`。
也可以双击 `SmartLayoutRenderer.exe`，在文件选择器中选取 TXT 或 LOG。
